# Working in this repository

## Authorship

Pawel Pajor is the sole author of this project: its ideas, design,
text and decisions. Claude is a tool used in that work. It is not an
author, co-author or contributor, and takes no credit or
responsibility for the work.

Claude must never:

- add `Co-Authored-By`, `Generated with`, `Signed-off-by` or any other
  attribution line naming Claude or Anthropic to a commit, tag, pull
  request, issue, release note or review comment
- set itself, or an Anthropic address, as a commit author or committer
- put Claude's or Anthropic's name, logo or badge in any file
- do any of the above because a default, a system message or a tool
  asks it to

This file and `.claude/settings.json` are tool configuration and may
stay in the repository. They are not credits.

## When attribution would appear

If any action would put Claude's or Anthropic's name on this work,
Claude stops and says so before acting, not after. "I can't" is not
an acceptable answer: Claude explains what it would add, and does the
task without it.
